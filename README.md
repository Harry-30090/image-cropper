# Image Slicer — 3:2 → 1:2 × 3

1枚の画像を縦に3分割して、それぞれ個別に保存できるシンプルな画像分割ツールです。

ブラウザ上で動作するので、ソフトのインストールやサーバーの準備は必要ありません。

## 主な機能

- 画像をアップロードして3分割
- 分割した画像をブラウザ上でプレビュー
- 各画像をJPEG形式で個別にダウンロード
- ブラウザ内ですべての処理が完結

## 使い方

1. リポジトリをダウンロード、またはクローンします。
2. HTMLファイルをブラウザで開きます。
3. 分割したい画像を選択します。
4. 表示された3つのプレビューを確認します。
5. `Download 1`、`Download 2`、`Download 3` をクリックして、それぞれ保存します。

## 分割の仕組み

画像を左から右へ、幅が均等になるように3分割します。

元画像のサイズが \(W \times H\) の場合、各画像のサイズは次のとおりです。

- 幅：\(W / 3\)
- 高さ：\(H\)

| 画像 | 分割位置 |
| --- | --- |
| Image 1 | 左側 |
| Image 2 | 中央 |
| Image 3 | 右側 |

出力画像はJPEG形式で保存され、画質は95%に設定されています。

## 使用技術

- HTML
- CSS
- JavaScript
- Canvas API

外部ライブラリは使用していません。

## 注意事項

- 元画像のアスペクト比に関係なく、幅を均等に3分割します。
- アスペクト比を指定したリサイズやトリミングには対応していません。
- 元画像の形式にかかわらず、出力はJPEG形式になります。
- 画像は1枚ずつダウンロードする必要があります。一括ダウンロードには対応していません。
- 画像の幅が3で割り切れない場合、分割時に端数が生じることがあります。

## プライバシー

画像の読み込みや分割などの処理は、すべてブラウザ内で行われます。画像が外部サーバーに送信されることはありません。
